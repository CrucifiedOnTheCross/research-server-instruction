# Данные и датасеты

Главное правило: личные файлы храните в личной папке, общие датасеты и проектные результаты - в общих папках проекта.

## Каталоги внутри JupyterLab

| Путь | Для чего нужен | Кто видит |
| --- | --- | --- |
| `/home/jovyan/work` | личные ноутбуки, черновики, промежуточные файлы | только рабочее окружение пользователя |
| `/srv/projects` | рабочие проектные данные | участники, которым папка подключена |
| `/srv/datasets` | исходные общие датасеты | обычно только чтение |
| `/srv/shared` | общие материалы | обычно только чтение |

Не кладите чувствительные, персональные или закрытые данные в общие папки без согласования с ответственным.

## Кто может увидеть мои данные

Данные в `/home/jovyan/work` считаются личной рабочей зоной пользователя.

Данные в `/srv/projects`, `/srv/datasets` и `/srv/shared` являются общими для тех пользователей, которым эти папки подключены. Если проект должен быть закрыт от других групп, заранее попросите администратора создать отдельную проектную папку с отдельными правами.

## Как загрузить небольшой датасет

Для небольших CSV, Excel, изображений, архивов и тестовых данных:

1. Откройте JupyterHub.
2. Запустите окружение.
3. Перейдите в `/home/jovyan/work`.
4. Используйте кнопку загрузки файлов в JupyterLab.

Для больших датасетов этот способ не подходит: загрузка через браузер может оборваться.

## Если датасет на внешнем диске

Передайте диск администратору и сообщите:

1. Название проекта.
2. Название датасета.
3. Примерный размер.
4. Куда положить данные: в общий датасет или в рабочую папку проекта.

Рекомендуемые места:

- `/srv/datasets/<dataset-name>` - исходный датасет, который не нужно менять;
- `/srv/projects/<project-name>` - рабочие данные проекта.

## Если датасет в облаке

Лучше скачивать данные сразу на сервер, а не сначала на личный компьютер.

Подходящие способы:

- `wget` или `curl` для прямой ссылки;
- `rclone` для Google Drive, Яндекс Диска, S3 и похожих хранилищ;
- Kaggle CLI для Kaggle;
- Hugging Face CLI или Python-код для Hugging Face.

Не вставляйте личные токены и пароли в общие ноутбуки. Если для скачивания нужны ключи доступа, настройте их только в своей личной папке или передайте администратору отдельным безопасным способом.

## Что сообщить ответственному для большого датасета

Перед загрузкой большого датасета напишите:

1. Название проекта.
2. Размер данных.
3. Где лежит датасет: диск, ссылка, облако, Kaggle, Hugging Face.
4. Нужен ли доступ только на чтение.
5. Кто должен видеть эти данные.
