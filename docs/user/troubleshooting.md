# Что делать, если что-то не работает

Перед обращением к ответственному соберите минимум информации. Это сильно ускоряет решение проблемы.

## Что указать в сообщении

Напишите:

1. Какой сервис не открывается или где возникла ошибка.
2. Подключены ли вы к университетской сети или VPN.
3. Ваш логин в JupyterHub.
4. Какой образ выбран.
5. Текст ошибки или скриншот.
6. Примерное время возникновения проблемы.
7. Что вы запускали перед ошибкой.

## Типовые проблемы

| Проблема | Что проверить |
| --- | --- |
| Не открывается `10.200.1.180` | подключение к университетской сети или VPN |
| Не открывается JupyterHub | адрес `http://10.200.1.180:8000` |
| Не пускает в JupyterHub | учетная запись могла быть еще не подтверждена |
| Нет нужной библиотеки | нужен другой или обновленный Docker-образ |
| Не видна GPU | выбран ли образ `CUDA 13 Lab (GPU)` |
| Ноутбук завис | попробуйте `Kernel -> Restart Kernel` |
| Зависло все окружение | `File -> Hub Control Panel -> Stop My Server -> Start My Server` |
| Контейнер не стартует | отправьте администратору текст ошибки и выбранный образ |

## Что не делать

- Не храните единственную копию важных данных только внутри временного контейнера.
- Не передавайте свои пароли другим людям.
- Не кладите персональные или закрытые данные в общие папки без согласования.
- Не запускайте неизвестные Docker-образы без согласования с ответственным.
