# GPU, ресурсы и мониторинг

Сервер подходит для задач с CPU, RAM и GPU, но ресурсы общие. Запускайте тяжелые расчеты осознанно и предупреждайте ответственного, если задача может занять много времени.

## Характеристики сервера

- CPU: Intel Core i7-14700KF
- RAM: 64 GB
- GPU: NVIDIA GeForce RTX 5080, 16 GB VRAM
- SSD: 1 TB

## Использование GPU

Для задач с видеокартой выберите окружение:

```text
CUDA 13 Lab (GPU)
```

В нем уже установлен JupyterLab и базовые библиотеки для научной работы, включая CuPy.

Проверка GPU внутри ноутбука:

```python
import cupy as cp

x = cp.arange(10)
print(cp.__version__)
print(int(x.sum()))
```

Если код выполнился без ошибки, GPU доступна.

## Ограничения ресурсов

По умолчанию пользовательский Jupyter-контейнер ограничен:

- CPU: до 4 ядер;
- RAM: до 8 GB.

Это нужно, чтобы один пользователь случайно не занял весь сервер. Если для задачи нужны другие лимиты, напишите ответственному.
