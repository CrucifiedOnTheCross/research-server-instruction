# Пользователи и доступ

Администратор управляет регистрацией пользователей через JupyterHub и доступом к проектным данным через группы и права на папки.

## Подтверждение регистрации в JupyterHub

Пользователь регистрируется сам:

```text
http://10.200.1.180:8000/hub/signup
```

Администратор подтверждает учетную запись:

1. Войдите в JupyterHub под администратором `nikita`: `http://10.200.1.180:8000`
2. Откройте страницу подтверждения: `http://10.200.1.180:8000/hub/authorize`
3. Найдите пользователя в списке.
4. Нажмите `Authorize`.
5. Сообщите пользователю, что вход разрешен.

Если страница `/hub/authorize` не открывается или пишет, что нет прав, проверьте, что вход выполнен именно под администратором JupyterHub.

## Админ-панель JupyterHub

Адрес:

```text
http://10.200.1.180:8000/hub/admin
```

Там можно смотреть пользователей и останавливать пользовательские серверы.

## Что делать, если пользователь не может войти

Проверьте:

1. Пользователь действительно зарегистрировался.
2. Пользователь подтвержден на `/hub/authorize`.
3. Пользователь открывает `http://10.200.1.180:8000`.
4. Пользователь подключен к университетской сети или VPN.
5. В логах JupyterHub нет ошибки запуска контейнера.

Логи:

```bash
sudo research-platform logs 200
```

## Права Linux

Обычным пользователям не нужно выдавать доступ к Docker.

Рекомендуемая логика:

- доступ в JupyterHub - через регистрацию и подтверждение;
- доступ к проектным данным - через проектные папки и Linux-группы;
- административные команды - только для `research-admins`;
- Docker/Portainer - только для администраторов.
