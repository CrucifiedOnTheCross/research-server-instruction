# Stage 3B: подтверждение переносимости LDAM-DRW между разбиениями

Статус: протокол зафиксирован до создания новых разбиений и до просмотра тестовых предсказаний.

## Научная задача

Stage 3A показал, что среди заранее заданных функций потерь только LDAM-DRW устойчиво превзошёл перекрёстную энтропию на уровне поражений: среднее изменение MCC составило `+0,0580`, 95%-й доверительный интервал `[0,0190; 0,0987]`, знак положителен для трёх из трёх начальных значений генератора случайных чисел. Однако результат получен на одном составе проверочной выборки. Stage 3B проверяет, переносится ли эффект на новые непересекающиеся по поражениям разбиения.

Основная гипотеза:

> LDAM-DRW повышает MCC на уровне поражений по сравнению с перекрёстной энтропией при изменении как состава разбиения, так и начального состояния модели.

## Основание в литературе

1. Cao et al. предложили частотно-зависимый отступ LDAM и отложенное перевзвешивание DRW. Каноническая конфигурация использует отступ, пропорциональный `n_c^(-1/4)`, и отделяет раннее обучение признаков от поздней коррекции дисбаланса. В Stage 3B сохраняются параметры Stage 3A: `max_margin=0,5`, `scale=30`, косинусный классификатор и начало DRW после 80% из 50 эпох. Источник: [*Learning Imbalanced Datasets with Label-Distribution-Aware Margin Loss*](https://proceedings.neurips.cc/paper_files/paper/2019/hash/621461af90cadfdaf0e8d4cc25129f91-Abstract.html), NeurIPS 2019.
2. Guo et al. показали, что скалярное масштабирование температуры является простым и эффективным способом последующей калибровки нейронных сетей. Температура оценивается только по проверочным предсказаниям минимизацией отрицательного логарифмического правдоподобия и затем без изменения применяется к тестовым данным. Эта ветка не участвует в выборе основного метода. Источник: [*On Calibration of Modern Neural Networks*](https://proceedings.mlr.press/v70/guo17a.html), ICML 2017, PMLR 70:1321-1330.
3. MONICA задаёт воспроизводимый контекст длиннохвостой классификации медицинских изображений. Наш протокол отличается более строгим разделением по `lesion_id` и отдельным анализом вариабельности разбиений. Источник: [*MONICA: Benchmarking on Long-tailed Medical Image Classification*](https://arxiv.org/abs/2410.02010), arXiv:2410.02010.

## Зафиксированный дизайн

### Разбиения

- начальные значения построения разбиений: `101`, `202`, `303`;
- единица разделения: `lesion_id`, а при его отсутствии уникальное изображение;
- в каждом классе: 100 тестовых, 50 проверочных изображений и длиннохвостая обучающая выборка `[5000, 2590, 1342, 695, 360, 187, 97, 51]`;
- пересечения поражений между обучением, проверкой и тестом должны быть нулевыми;
- контрольные суммы всех описаний выборок сохраняются в `data_splits/stage3b/split_registry.json`.

### Матрица обучения

| Фактор | Значения |
|---|---|
| Метод | перекрёстная энтропия; LDAM-DRW |
| Начальное значение разбиения | 101; 202; 303 |
| Начальное значение модели | 42; 43; 44 |
| Число обучений | 18 |
| Архитектура | ResNet-50, ImageNet-1K V2 |
| Эпохи | 50 без ранней остановки |
| Пакет | 256, один шаг накопления |
| Оптимизатор | Adam, скорость обучения `3e-4`, без уменьшения весов |
| Формат | bfloat16, channels-last |
| Основная контрольная точка | `last.pt`, эпоха 50 |
| Дополнительная | `best.pt` по MCC на уровне поражений |

Из каждого из девяти запусков с перекрёстной энтропией рассчитывается коррекция логитов с `tau=1`. Для каждого из девяти запусков LDAM-DRW отдельно оценивается скалярная температура по проверочной выборке. Производные расчёты выполняются параллельно и не требуют обучения.

## Защита тестовой выборки

Обучающие конфигурации не содержат `test_csv`, а `run_test=false`. После 18 обучений проверяются:

- единый коммит кода;
- уникальная сигнатура каждого запуска;
- контрольные суммы обучающей и проверочной выборок;
- 50 завершённых эпох;
- политика `last.pt` как основная;
- наличие всех структурированных артефактов;
- отсутствие тестовых предсказаний;
- наличие девяти коррекций логитов и девяти температур, рассчитанных только по проверке.

Тест открывается только при `readiness.ready=true` и только один раз. Файл `TEST_EVALUATION_STARTED.json` запрещено удалять или обходить.

## Метрики и критерий подтверждения

Основная величина: `MCC_LDAM - MCC_CE` на уровне поражений для `last.pt`.

Дополнительные показатели: сбалансированная точность, макроусреднённые F1/AUROC/AUPRC, худшая полнота класса, показатели MEL/AK/SCC, ECE, отрицательное логарифмическое правдоподобие, оценка Брайера, показатели на уровне изображений и вычислительная стоимость.

Подтверждение требует одновременно:

1. нижняя граница объединённого иерархического 95%-го доверительного интервала изменения MCC выше нуля;
2. среднее изменение MCC положительно не менее чем для двух из трёх разбиений;
3. отсутствует устойчивое клинически значимое падение полноты MEL или SCC;
4. результат не определяется одним начальным значением модели.

Иерархическая повторная выборка включает уровни `split seed -> model seed -> lesion_id` и не менее 10 000 повторов. Анализ `best.pt` и температурной калибровки является дополнительным и не заменяет основной результат.

## Вычислительная организация

Одновременное обучение нескольких моделей на одной RTX 5080 не применяется: оно меняет конкуренцию за память и вычислительные блоки и ухудшает сопоставимость. GPU-обучения выполняются последовательно; ожидаемая загрузка GPU близка к 100%, пиковая память около 11 ГиБ. Загрузка изображений использует 12 процессов, закреплённую память, четыре предварительно загруженных пакета на процесс и 24 ГиБ общей памяти контейнера. Построение трёх разбиений, проверка артефактов, калибровка и статистический анализ распараллеливаются по независимым заданиям.

Оценка длительности: около 3,5 часа обучения и до 30 минут на производные расчёты, одноразовую проверку теста и 10 000 повторов статистического анализа.

## Ограничения

- Эффект относится к полному пакету `косинусный классификатор + LDAM + DRW`; вклад компонентов будет проверяться отдельной абляцией только после подтверждения.
- Проверяются три разбиения и три начальных состояния модели, что лучше одного разбиения, но не заменяет внешнюю проверку.
- Температура использует ту же проверочную выборку, что и контроль контрольной точки; поэтому калибровочные результаты трактуются как дополнительные.
- Синтетические данные до завершения Stage 3B не используются.
