# Проекты и данные

Эта страница нужна администратору, который принимает датасеты, создает проектные папки и следит за правами доступа.

## Базовые каталоги

```text
/srv/research/users
/srv/research/projects
/srv/research/datasets
/srv/research/shared
```

Внутри JupyterLab они видны пользователю как:

```text
/home/jovyan/work
/srv/projects
/srv/datasets
/srv/shared
```

## Что считать личным, проектным и общим

| Тип данных | Где хранить | Комментарий |
| --- | --- | --- |
| Личные ноутбуки и черновики | `/srv/research/users/<login>` | подключается как `/home/jovyan/work` |
| Рабочие данные проекта | `/srv/research/projects/<project-name>` | можно давать доступ группе проекта |
| Исходные датасеты | `/srv/research/datasets/<dataset-name>` | желательно только чтение |
| Общие материалы | `/srv/research/shared` | инструкции, примеры, справочные файлы |

## Создать проект

Используйте helper-команду:

```bash
sudo research-create-project PROJECT_NAME
```

После создания проверьте права и владельца:

```bash
ls -ld /srv/research/projects/PROJECT_NAME
```

## Закрытые проекты

Если проект не должен быть виден всем пользователям:

1. Создайте отдельную Linux-группу проекта.
2. Назначьте группу владельцем проектной папки.
3. Выдайте права только нужным пользователям.
4. Подключайте проектную папку только нужным окружениям.

Не храните чувствительные или персональные данные в общих папках без отдельного решения по правам.

## Загрузка датасета с диска

Рекомендуемый порядок:

1. Подключите внешний диск к серверу.
2. Скопируйте данные в `/srv/research/datasets/<dataset-name>` или `/srv/research/projects/<project-name>`.
3. Проверьте размер и права.
4. Сообщите пользователю путь внутри JupyterLab.

Для исходных датасетов предпочтителен режим только для чтения.

## Загрузка датасета из облака

Подходящие инструменты:

- `wget` или `curl` для прямых ссылок;
- `rclone` для Google Drive, Яндекс Диска, S3 и похожих хранилищ;
- Kaggle CLI;
- Hugging Face CLI.

Токены и ключи доступа не должны попадать в общие ноутбуки и публичную документацию.
