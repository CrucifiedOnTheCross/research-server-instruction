# Research Server Wiki

Сервер `10.200.1.180` предназначен для научных вычислений, работы в JupyterLab, запуска воспроизводимых Docker-окружений, хранения проектных данных и мониторинга ресурсов.

## Куда идти пользователю

Если вы впервые заходите на сервер:

1. Откройте [Быстрый старт](user/getting-started.md).
2. Разберитесь, где хранить файлы: [Данные и датасеты](user/data.md).
3. Если нужны библиотеки или свой образ, откройте [Окружения, библиотеки и Docker-образы](user/environments.md).
4. Если нужна видеокарта, откройте [GPU, ресурсы и мониторинг](user/gpu-and-monitoring.md).
5. Если что-то сломалось, откройте [Что делать, если что-то не работает](user/troubleshooting.md).

Основной сервис для ученых - JupyterHub:

```text
http://10.200.1.180:8000
```

## Куда идти администратору

Если вы администрируете сервер:

1. Начните с [обзора платформы](admin/overview.md).
2. Для регистрации и доступа пользователей используйте [Пользователи и доступ](admin/users.md).
3. Для проектных папок и датасетов используйте [Проекты и данные](admin/data-and-projects.md).
4. Для новых окружений и контейнеров используйте [Docker-образы и отдельные контейнеры](admin/images-and-containers.md).
5. Для перезапуска, логов и мониторинга используйте [Эксплуатация и мониторинг](admin/operations-monitoring.md).
6. Для правил доступа и рисков используйте [Безопасность](admin/security.md).
